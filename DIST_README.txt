================================================================
  KERR // BLACK HOLE SANDBOX
  克尔黑洞沙盒 — 广义相对论实时仿真
================================================================

【运行】
  双击 KerrBlackHole.exe 即可。
  首次启动会预编译 GPU 内核（约 10-30 秒，控制台有提示），
  之后启动命中缓存，很快。

【系统要求】
  - Windows 10/11 64 位
  - 推荐 NVIDIA 显卡（CUDA）；其他显卡会自动回退 Vulkan
  - 显存建议 6 GB 以上（默认粒子池 800 万）

【操作】
  鼠标左键拖动     转向
  W A S D          移动（Shift 加速，Q/E 升降）
  鼠标右键按住     瞄准（彩色预测线：红=坠入 橙=逃逸 绿=束缚轨道）
  右键松开         发射恒星 / 反光铁球
  P                截图（保存到 renders\）
  ESC              退出
  视界不是墙 —— 可以直接飞进黑洞内部。

【面板（窗口左侧）】
  SPACETIME : 自旋、时间流速、红移、束流
  LAUNCH    : 恒星/铁球、速度、半径、质量比（定潮汐半径）、
              粒子数、圈化耗散、AUTO DISK STAR 一键成盘恒星
  DISPLAY   : 背景（星空/天球网格/立体网格）、分辨率、步数、曝光、辉光
  RECORD    : 录制演化动画帧序列（ffmpeg 合成命令见控制台）

【物理】
  Kerr 度规（Kerr-Schild 坐标），光线与粒子均为测地线积分；
  恒星为自引力束缚的粒子群，潮汐半径 r_t ~ R*(M_BH/M*)^(1/3)；
  摩擦加热 + 辐射冷却决定颜色（黑体谱）；
  多普勒 + 引力红移精确计算。几何单位 G = c = M = 1。

  本程序为物理可视化沙盒，不构成 GRMHD 级别的定量模拟。
